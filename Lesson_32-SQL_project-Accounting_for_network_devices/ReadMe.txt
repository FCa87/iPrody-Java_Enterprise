Project Name
Учетная система сетей

Requirements
Java 21

Description
Приложение для учёта и управления сетевыми объектами (сетями, устройствами и их взаимосвязями). Позволяет регистрировать сети, добавлять к ним устройства (например, роутеры, свитчи, серверы) и задавать связи между устройствами (например, подключение по кабелю или по Wi-Fi).

Usage
1. Добавление новой сети. Пользователь через консоль вводит название и описание сети. После подтверждения данные сохраняются в базе данных, а результат операции выводится в консоль.
2. Добавление устройства в сеть. Пользователь выбирает существующую сеть, вводит данные устройства (название, IP, MAC, тип, статус) через консоль, после чего устройство добавляется с привязкой к выбранной сети.
3. Регистрация подключения между устройствами. Пользователь выбирает два устройства (из одной или разных сетей), указывает тип подключения, и создается запись о подключении. Результат операции также отображается в консоли.
4. Редактирование и удаление записей. Через консоль пользователь может изменять данные сети или устройства, а также удалять записи (при условии соблюдения логики целостности данных). Все действия сопровождаются выводом сообщений о статусе выполнения.
5. Поиск и фильтрация устройств и сетей. Функционал для поиска устройств и сетей по различным критериям (название, IP-адрес, тип, статус).
6. Отображение сводной информации:
	а) всех устройств и соответствующих им подключений в сети;
	б) всех сетей и подключенных к ним устройств.
7. Возможность генерации простых отчётов по сетевым объектам (например, количество активных устройств в сети).
